# Distributed AI Systems

This is the source code for the book *Distributed AI Systems* by Fuheng Wu.

![](https://m.media-amazon.com/images/I/718Je+tIL3L._SL1500_.jpg)

Official website: [distaisys.com](https://distaisys.com) — mind maps, study materials, reader group, problem sets, videos, seminars to support your learning.

This repository is actively maintained. If you find a bug, have a question about the code, or run into issues getting an example to run, please open an issue or pull request — updates and fixes will continue to be published here as the book evolves.

## Setup

For chapter 1-4, to run the code, install the dependencies:

```bash
pip install torch torchvision numpy distai
```

For other chapters, please check the requirements.txt in each chapter folder, and run:

```bash
pip install -r requirements.txt
```
